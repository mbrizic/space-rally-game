# Dormant / Supported but Inactive

This file lists features that are implemented (or partially implemented) in code, but are currently not exposed in the UI / gameplay.

- Replay system: record/export/import/playback exists in code, but UI entry points are currently removed.
- Balrog/Colossus boss: exists in code, but currently disabled.
- Sandstorm zones: serialization, runtime grip/drag modifiers and minimap support exist, but all biomes disable generation; normal stages do not currently feature sandstorms.
